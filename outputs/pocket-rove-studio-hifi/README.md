## 高保真处理

1. 以高分段圆角矩形挤出手机，平面圆角与机身厚度分别控制。
2. 独立制作钛金属机身、窄抛光倒角、黑色陶瓷玻璃边缘、侧键和聚合物天线隔断。
3. 金属微小粗糙度变化、细颗粒石材展台；屏幕仅添加0.8%的受控玻璃反射。
4. 真实曲面摄影棚、五盏矩形柔光灯和两侧遮光板，保留接触阴影与反射层次。
5. 95mm透视镜头，保持屏幕清晰；2160×3840，Cycles，M4 Metal GPU，256 samples上限、自适应采样与降噪。

这不是图像生成模型重绘的手机界面，也未使用超分模型补造文字。屏幕仍来自原始1206×2622截图，成片分辨率不代表屏幕素材新增了真实细节。

## 编辑

- `PHONE / master transform`：统一控制设备姿态。
- `SCREEN / replace original image`：材质图片节点中换图。
- `TYPE / headline`、`TYPE / support`等：修改标题及说明。
- `LIGHT / …`：调整光源。
- `CAMERA / 4K portrait`：镜头与构图。

替换截图时优先使用1206:2622比例，其他比例应同时调整屏幕几何与UV。F12可重新渲染。

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -t 6 --python build_hifi.py -- --screen /absolute/path/to/screen.png
```

脚本会重建本目录的同名最终场景和图片。在 Blender 手动修改过场景时，先另存新版本再运行脚本。
